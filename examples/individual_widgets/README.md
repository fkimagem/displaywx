# Manuais dos exemplos individuais

Escolha um exemplo para aprender a montar, configurar e usar seus widgets. Cada manual contém imagem, programa completo, explicação por partes e uma referência dos métodos de uso no `.ino`, baseada nos fontes locais da DisplayWX 1.0.33.

Leia as ligações do manual escolhido antes de montar. As tabelas de GPIOs correspondem aos pinos definidos nos arquivos `.ino`: os periféricos externos usam GPIOs separados dos sinais do display, backlight e toque. O exemplo de câmera usa ESP32-P4; os demais usam ESP32-S3 com ST7796 e FT6336U.
